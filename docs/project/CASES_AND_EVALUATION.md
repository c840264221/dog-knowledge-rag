# 实际案例与评估口径

## 已运行案例

1. 图文 PDF：页面渲染、视觉模型提取、人工修正、文字切块向量化和关联图片引用。固定候选提问项圈颜色，纯文字组报告证据不足，附图组回答黄色；不是整体多模态准确率。
2. 跨语言排障：从最终上下文逆向检查召回和重排名次；固定候选比较中文／英文问题及不同模型，区分漏召回与排序截断。
3. Skill＋MCP：自然语言提取分类、实际账单日期、金额；缺参多轮恢复、写入人工确认、持久化回执和同键幂等处理。
4. 知识→预算：根据接猫资料筛选用品再计算预算，Skill 区分候选价格表与用户已选清单；推断项标注，不把准备采购当作实际消费。
5. 独立知识任务并发：运输准备及猫狗首次接触两个步骤执行区间重叠，分别保留引用。区间重叠不等同于性能提升百分比。
6. 长任务：步骤边界前台预算移交、计划阶段后台执行、保留前置结果、Redis 可靠提交回执；不宣称强制中止任意外部调用或跨系统恰好执行一次。
